# Parent Teacher Conference Form

A simple and responsive **HTML & CSS web form** designed to collect information for scheduling parent‑teacher conferences.  
The form focuses on accessibility, clarity, and user‑friendly input handling.

---

## 📋 Features

- Structured form layout using semantic HTML
- Input validation with `required` fields
- Radio button selection for preferred contact method
- Text area for additional notes or concerns
- Responsive design using viewport meta tag
- Clean and readable UI with external CSS styling

---

## 🛠️ Technologies Used

- **HTML5** — form structure and semantic elements
- **CSS3** — layout, styling, and visual enhancements

---

## 📂 Project Structure

├── index.html
├── styles.css
└── README.md

---

## 🚀 How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Fill out the form and submit

This project is static and does not include backend form handling.
